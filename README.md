# About Me — Personal Page

Aesthetic minimalist About Me page, ready for **GitHub Pages**.

## How to deploy to GitHub Pages

1. Create a new repository on GitHub (example name: `username.github.io` or any name).
2. Upload these files:
   - `index.html`
   - `style.css`
3. Go to **Settings → Pages**.
4. Under **Source**, select **Deploy from a branch**.
5. Choose branch `main` (or `master`) and folder `/ (root)`.
6. Save. Your site will be live at:
   - `https://username.github.io` (if repo name is `username.github.io`)
   - or `https://username.github.io/repo-name`

## Customize

1. **Profile photo**  
   Save a photo of Hanni Pham (or any photo you like) as `profile.jpg`  
   and put it in the same folder as `index.html`.

2. Open `index.html` and change:
   - `Your Name` → your real name
   - Social links (GitHub, Instagram, Email)
   - Any text you want to personalize

That’s it!
